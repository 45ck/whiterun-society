# Compile-only interface declarations

These minimal, original declarations describe only the native signatures used by WSSocietyRouter. They contain no implementations or extracted game source. Never compile or deploy these base types into Skyrim; the owned game supplies the real scripts. Compile only `papyrus/WSSocietyRouter.psc` with this folder on the import path.

The function interfaces can be checked against [Skyrim Platform's generated native declarations](https://github.com/skyrim-multiplayer/skymp/blob/main/skyrim-platform/src/platform_se/codegen/convert-files/skyrimPlatform.ts). Compilation proves syntax and type compatibility with these declarations, not in-game execution.
